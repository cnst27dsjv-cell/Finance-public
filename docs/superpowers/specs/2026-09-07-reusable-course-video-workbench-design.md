# InvestQuest 可复用课程视频工作台设计

## 背景

现有 L1-1 与 L1-2 的布局编辑器均以单课、单页面方式实现，能够移动、缩放和旋转已有元素，但缺少统一的数据模型、元素创建能力、完整图层管理和可参与的动效编排。随着课程数量增加，继续复制编辑器会造成重复开发、跨浏览器差异、配置格式分裂，以及编辑结果与 HyperFrames 渲染结果不一致。

本设计建立一个可复用的课程视频工作台。用户负责类似 PPT 的画面排版与动效顺序调整；Codex 负责复杂动画实现；HyperFrames 负责确定性预览和渲染；ElevenLabs 负责分段旁白；ChatCut 负责字幕、音频、转场和最终成片精修。

## 目标

- 使用一个共享工作台编辑不同课程和不同分镜。
- 像 PPT 一样添加、选择、复制、移动、缩放、旋转和排列元素。
- 支持文字、基础图形、线条、箭头、图标和图片。
- 支持每个分镜独立的图层顺序、显示状态与锁定状态。
- 在不暴露复杂动画参数的前提下，让用户调整元素出现顺序、开始时间和持续时间。
- 让编辑预览与 HyperFrames 最终渲染读取同一份配置。
- 输出可继续在 ChatCut 中手动调整的分镜视频、分段旁白和字幕时间数据。

## 非目标

- 不在工作台内重建完整的非线性视频剪辑软件。
- 不在第一版开放 GSAP 曲线、骨骼参数或逐笔路径等底层动画参数。
- 不替代 ChatCut 的字幕样式、音频混音、转场和整集时间线能力。
- 不立即删除现有 L1-1、L1-2 编辑器；迁移完成前保留原实现作为回退。

## 已确认方案

采用“同一工作台、双模式”的结构：

- **画面编辑模式**：编辑元素内容、位置、尺寸、旋转、样式和图层。
- **动效编排模式**：在同一画布、同一元素 ID 上编辑出现顺序、开始时间和持续时间。

不采用两个完全独立的编辑页面，因为 JSON 交接和页面切换容易导致版本不一致；不采用完整剪辑时间线，因为其功能与 ChatCut 大量重叠，开发和维护成本过高。

## 总体工作流

1. 确认课程内容、题目覆盖、脚本和分镜。
2. 在画面编辑台调整每个分镜的排版与元素样式。
3. 按分镜生成分段旁白，保留真实音频时长与句间气口。
4. 根据旁白和文本内容生成第一版动画、音效和逐句字幕时间。
5. 在动效编排台调整元素出现顺序、开始时间和持续时间。
6. HyperFrames 根据最终配置重新渲染分镜视频。
7. 将分镜视频、分段旁白、字幕时间文件、音效和音乐导入 ChatCut。
8. 在 ChatCut 中手动调整字幕断句、字体、大小、颜色、位置，调整音频片段、气口、音量、淡入淡出、动画和音效。
9. 完成画面、音频、字幕、比例和时长检查后导出 MP4。

字幕默认采用逐句显示，仅对核心金融关键词进行颜色高亮，不默认使用密集逐字跳动效果。

## 系统结构

### 共享工作台

共享实现放在 `video/shared/` 下，由通用编辑器核心和课程适配配置组成。工作台不直接写死课程内容。

每门课程提供一个项目配置，至少包含：

- 项目标识、课程编号和标题；
- 画布宽高、帧率和默认时长；
- 分镜清单与分镜预览入口；
- 原始页面中允许编辑的稳定元素 ID；
- 元素名称、类型、分类和默认图层；
- 配音、字幕和动效时间数据入口；
- 配置格式版本。

默认画布为 1920×1080，但宽高与比例必须由项目配置决定，以支持后续竖屏或其他页面场景。

### 统一元素模型

工作台同时处理两类元素：

1. **源元素**：课程页面中已经存在的 HTML 或 SVG 元素，通过稳定的编辑器 ID 注册。
2. **新增元素**：用户在工作台内创建的文字、矩形、圆形、线条、箭头、图标和图片。

两类元素使用相同的基础属性：

- `id`、`name`、`type`；
- `x`、`y`、`width`、`height`；
- `rotation`、`opacity`；
- `zIndex`、`visible`、`locked`；
- 类型对应的样式与内容；
- 动效编排引用。

线条额外保存起点、终点、弯曲控制点、描边宽度、虚实样式，以及起点/终点箭头类型。文字保存内容、字体、字号、字重、颜色、对齐、行高和文本框尺寸。

### 单一项目文件

画面编辑与动效编排共用一份带版本号的项目 JSON。其主要结构包括：

- 项目与画布信息；
- 分镜列表；
- 每个分镜的元素及图层；
- 布局和样式覆盖；
- 动效时间块；
- 配音分段、句子和关键词时间锚点；
- 资源引用和校验信息。

浏览器草稿、下载文件、HyperFrames 预览和最终渲染必须使用同一数据模型。格式升级通过显式版本迁移处理，不静默丢弃旧字段。

## 画面编辑模式

### 工作区布局

- 左侧：分镜缩略图列表。
- 中央：可缩放画布与对齐参考线。
- 顶部：选择、文字、图形、线条、箭头、图标、图片、复制、删除、撤销和重做。
- 右侧：属性面板与图层面板。
- 底部：画面编辑模式显示简洁状态栏，动效编排模式展开时间条。

### 编辑能力

- 点击画布或图层列表选中元素，两个入口保持同步。
- 拖动移动，控制点等比或自由缩放，旋转手柄调整角度。
- 线条支持拖动端点与弯曲控制点，并可切换无箭头、单向箭头或双向箭头。
- Shift 多选，支持成组移动和对齐。
- 支持复制、删除、锁定、隐藏和重命名。
- 支持画布边缘、中心线、其他元素边缘与中心的吸附。
- 支持水平/垂直对齐和等距分布。
- 键盘方向键精细移动，常用复制动作提供快捷键。

### 图层系统

每个分镜维护独立、明确的图层顺序：

- 图层面板顶部代表画面最上层。
- 支持拖拽排序、上移一层、下移一层、置于顶层和置于底层。
- 支持显示/隐藏、锁定/解锁和重命名。
- 画布选中与图层选中双向同步。
- 复合角色或固定结构可以作为一组显示，但组内元素仍保留稳定 ID，便于动画系统引用。

## 动效编排模式

### 交互模型

切换到动效编排模式后，保持当前分镜和当前选中元素，底部展开当前分镜的时间条。

每个可动画元素显示为一个时间块，包含：

- 元素名称；
- 只读的动画类型摘要；
- 开始时间；
- 持续时间；
- 编排关系：与上一项同时、上一项之后或指定时间开始；
- 可选的句子或关键词时间锚点。

用户可以拖动时间块改变开始时间，拖动边缘改变持续时间，并通过排序调整默认出现顺序。工作台不在第一版开放 GSAP 曲线、路径细节或角色骨骼参数。

### 配音同步

配音数据按分镜、句子或自然语义段保存，不把整集旁白视为一个不可拆分音频块。时间条显示：

- 音频波形；
- 每句话的起止范围；
- 核心金融关键词时间点；
- 分镜边界。

动画时间块可以吸附到句子或关键词。改变元素在原分镜内部的顺序不修改字幕；改变分镜总时长时，系统重新计算受影响的字幕和音效时间，并保留调整前快照。

任何自动重算都只是可编辑初稿。进入 ChatCut 后，用户仍可手动覆盖字幕与音频时间。

## HyperFrames 集成

- 预览渲染与最终渲染使用同一个项目 JSON 和同一个课程适配器。
- 复杂动效由课程代码实现，并通过稳定元素 ID 与时间块绑定。
- 工作台只覆盖用户允许调整的编排字段，不覆盖未暴露的动画实现细节。
- 分镜优先单独渲染，便于替换、延长停留和在 ChatCut 中重新排序。
- 如果时间块超出分镜范围，预览显示警告但不擅自截断。

## ElevenLabs 与 ChatCut 集成

### ElevenLabs

- 按分镜或语义段生成旁白。
- 记录每个音频文件的真实时长，不用估算时长直接落位。
- 句间使用统一气口；需要精确同步时优先生成独立语句或句组。
- 将音频和句子/关键词时间信息交给动效编排台。

### ChatCut

工作台生成一个 ChatCut 交付包，包括：

- 各分镜渲染视频；
- 分段旁白音频；
- 逐句字幕时间文件；
- 核心词高亮信息；
- 音效和背景音乐素材；
- 分镜顺序与时长清单。

ChatCut 负责整集时间线、字幕样式与位置、音频剪切和混音、转场、补充 MG、音效微调和最终导出。字幕和音频必须保持为可编辑轨道，不在进入 ChatCut 前全部烧录或混成一个不可编辑文件。

## 保存、撤销与版本

- 修改后自动保存浏览器草稿。
- 提供项目 JSON 下载和导入。
- 支持撤销、重做和关键版本快照。
- 导入旧格式时先验证并迁移；迁移失败时保留原文件并给出明确错误。
- 资源路径、元素 ID 或版本不匹配时不得静默忽略。

## 自动校验

导出或渲染前检查：

- 元素是否超出画布；
- 文本是否溢出或被裁切；
- 元素是否因图层顺序被意外遮挡；
- 是否存在重复、缺失或失效的元素 ID；
- 线条端点和控制点是否有效；
- 动画是否超出分镜范围；
- 图片、字体和音频资源是否缺失；
- 配音、字幕、关键词与分镜时间是否匹配；
- 视频比例、分辨率、帧率和总时长是否符合配置。

严重错误阻止导出；可接受但值得检查的问题显示警告，并允许用户明确继续。

## 跨浏览器要求

- Safari、Chrome 和 Codex 内置浏览器使用相同的 Pointer Events 交互路径。
- 不依赖字体加载完成才初始化编辑器；字体加载只触发后续尺寸校正。
- 画布直接选择、图层选择、拖拽、缩放、旋转和线条控制点均需进行跨浏览器验证。
- 界面缩放不能改变项目坐标，所有保存值使用画布坐标或标准化坐标。

## 实施阶段

1. 建立共享工作台核心、项目适配器和统一 JSON 格式。
2. 实现画面编辑、元素创建、属性面板和图层系统。
3. 用 L1-2 八个分镜接入并验证 HyperFrames 预览还原。
4. 实现配音时间数据导入和动效编排模式。
5. 实现校验与 ChatCut 交付包。
6. 验证稳定后迁移 L1-1，并将新课程接入方式写入课程视频 Skill。

## 验收标准

- 用户能在 L1-2 八个分镜中稳定选中并编辑所有注册元素。
- 用户能添加、复制和删除文字、基础图形、线条、箭头、图标和图片。
- 用户能通过图层面板明确控制元素处于底层或最上层。
- 编辑结果下载、重新导入后无位置、样式、图层或元素丢失。
- HyperFrames 预览和最终渲染与工作台布局一致。
- 导入分段配音后，用户能调整元素出现顺序、开始时间和持续时间。
- 改变分镜时长时能识别字幕与音效的受影响范围，并生成可手动修正的同步结果。
- 可生成保留字幕和音频可编辑性的 ChatCut 交付包。
- Safari、Chrome 和 Codex 内置浏览器的核心编辑操作均通过验证。
