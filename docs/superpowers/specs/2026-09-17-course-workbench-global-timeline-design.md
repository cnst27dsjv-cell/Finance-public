# InvestQuest 工作台整课统一时间轴设计

## 背景

当前动效编排按分镜分别显示时间轴。字幕只能在当前分镜时长内移动，播放头也只表示分镜内时间。第二课的旁白实际来自同一段连续录音，因此跨分镜校准字幕时需要反复切换页面，容易造成字幕、声音和画面边界不一致。

## 目标

- 动效编排模式显示从 S01 到 S08 的整课时间轴。
- 所有分镜、字幕、音效和元素动画共用一根红色播放线。
- 播放或拖动经过分镜边界时，画布自动切换到对应分镜。
- 字幕可以跨分镜边界拖动，并自动归入目标分镜。
- 分镜之间加入翻页画面转场和对应的轻量翻页音效。
- 保持现有项目 JSON、浏览器草稿、独立预览和最终渲染兼容。

## 不做的内容

- 不增加视频素材裁切、多机位、调色等通用剪辑能力。
- 不允许元素动画跨越分镜；元素仍属于自己的画面。
- 不改变现有旁白文件，也不拉伸录音。
- 不通过插入额外空档改变课程总时长。

## 已确认方案

采用“连续整课时间轴，分镜数据仍分开保存”的方案。界面以整课绝对时间显示，保存时继续使用当前按分镜存储的相对时间，减少对渲染和交付流程的影响。

不采用在分镜间插入额外转场时长的方案，因为它会推动后续所有字幕和旁白时间。翻页转场覆盖在上一分镜末尾，默认持续 0.5 秒，不增加总时长。

## 时间模型

工作台根据分镜顺序和时长计算每个分镜的绝对区间：

`sceneStart = 前面所有分镜时长之和`

`absoluteTime = sceneStart + localTime`

界面拖动使用绝对时间。进入某个分镜时，再换算为该分镜内时间供现有画面动画、字幕渲染和音频片段使用。

旁白音频继续作为播放时钟。第二课每个分镜的语音片段已有 `mediaStart`，播放头进入新分镜后，从对应媒体位置继续播放。跨越边界时只切换画面与当前分镜状态，不重新从音频开头播放。

## 时间轴界面

动效模式的时间轴由以下部分组成：

1. **画面分镜轨道**：连续显示 S01 至 S08，每个块的宽度由真实分镜时长决定。
2. **字幕轨道**：显示整课全部字幕块。字幕文字保留当前颜色和选中行为。
3. **音效轨道**：显示整课全部音效，包括知识点提示和翻页音效。
4. **当前分镜元素轨道**：只显示当前画面的元素动画，避免八个分镜的所有图层同时展开导致时间轴过长；这些动画块按整课绝对位置对齐。

时间刻度、滑杆和所有轨道使用相同左右边界。红色播放线从顶部贯穿所有轨道。当前分镜块高亮，画布标题继续显示当前 S 编号和标题。

左侧缩略图仍可直接切换分镜。点击缩略图时，播放头跳到该分镜的起点；在画面编辑模式中保持现有切换行为。

## 跨分镜字幕

拖动字幕主体改变整课绝对开始时间，拖动右边缘改变结束时间。

当字幕主体完全移动到另一分镜时：

- 从原分镜的 `voice.sentences` 中移除；
- 加入目标分镜的 `voice.sentences`；
- 将绝对起止时间换算成目标分镜内的相对时间；
- 保留字幕 ID、文字和对齐来源等其他字段；
- 画布自动切换到目标分镜，方便立即检查。

字幕不允许横跨两个分镜。若拖动或拉长导致字幕越过边界，字幕整体吸附到最接近且容得下它的分镜；若该字幕比目标分镜还长，则恢复本次操作并显示错误。这样可以保持现有按分镜渲染和 SRT 导出逻辑明确。

字幕时间字段在属性面板中显示整课时间，同时补充分镜内时间说明，避免用户误把两个计时体系混用。

## 分镜播放与音频同步

整课播放状态保存一个绝对播放时间。每次更新时：

1. 由绝对时间确定当前分镜和分镜内时间；
2. 必要时切换画布，但不重置播放状态；
3. 将分镜内时间交给现有画面动画和字幕渲染；
4. 将当前分镜及分镜内时间交给音频预览器；
5. 优先采用音频媒体的实际播放位置校正红色播放线。

用户在任意位置暂停、拖动并继续播放时，旁白从该绝对时间对应的媒体位置继续。

## 翻页转场

每个非末尾分镜在结束前 0.5 秒进入翻页转场：

- 当前画面像纸页一样向左翻出；
- 下一画面同步从右侧进入；
- 转场只作用于预览和最终渲染的分镜容器，不修改分镜内部元素位置；
- 转场区间在画面分镜轨道边界处显示明确标记；
- 同一位置播放轻量翻页音效，音量低于旁白；
- 若项目已有临时 `whoosh-short` 翻页占位音效，则沿用时间点并替换为翻页语义，不重复播放两份音效。

转场与上一分镜末尾重叠，因此八个分镜的总时长仍等于现有时长之和，旁白、字幕和音效无需整体后移。

## 保存与兼容

整课起点属于界面派生数据，不重复写入每个元素。现有分镜时长和相对时间仍是项目文件的持久数据。

项目新增一项可选的整课转场设置，包含类型、时长和音效。旧项目缺少该字段时使用默认翻页设置，因此原浏览器草稿和已下载 JSON 可以继续打开。导出、独立预览和渲染器读取同一设置。

撤销一次字幕跨分镜移动时，字幕应回到原分镜和原时间。保存后重新导入必须保持字幕归属、绝对顺序和转场设置。

## 异常处理

- 旁白尚未载入时，播放头可按页面时间预览画面，但状态栏提示音频未就绪。
- 音频播放失败时停止整课播放，保留当前绝对时间并显示现有错误信息。
- 分镜时长修改后重新计算后续分镜的绝对起点，不改动各分镜内部字幕时间。
- 删除或缺失分镜时拒绝加载不完整项目，不静默移动字幕。

## 验收标准

- 时间轴连续显示 S01 至 S08，并只有一根贯穿所有轨道的红色播放线。
- 从课程开头播放到结尾时，画面在边界自动切换，旁白不中断且字幕与声音保持同步。
- 将一条字幕从 S01 拖到 S02 后，画布切换到 S02；保存并重新导入后位置不变。
- 字幕不能停留在两个分镜之间，也不能超出课程总时长。
- 拖动到任意分镜中部后播放，旁白、字幕、画面动画和红色播放线从同一点继续。
- 七个分镜边界均显示并播放约 0.5 秒翻页转场，不改变课程总时长。
- 现有画面编辑、全局字幕样式、音效编辑、项目导入导出、独立预览和最终渲染继续可用。
- 自动测试覆盖绝对时间换算、边界归属、跨分镜字幕迁移、撤销和项目往返保存。
