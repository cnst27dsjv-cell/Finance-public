# 课程工作台全局字幕位置与样式设计

## 目标

让用户在编辑台中直接调整字幕位置，并让调整结果一次应用到第二课全部 83 条字幕。字幕样式也采用全片统一设置，确保八个分镜在编辑台、独立预览和最终渲染中的位置与视觉完全一致。

## 用户交互

在“动效编排”模式中，只要当前时间存在字幕，字幕画面上方会出现可选区域。用户点击字幕后可直接拖动；拖动修改的是项目级字幕中心位置，因此所有分镜和所有字幕同步更新。

选中画面字幕或字幕时间块后，右侧显示两组设置：

1. 当前字幕：文字、开始时间和结束时间，继续允许逐条编辑。
2. 全局字幕：样式预设、中心 X、中心 Y、最大宽度、字号和底板透明度。全局字段的任何修改都会立即作用于全部字幕。

字幕位置不提供逐条覆盖，也不按分镜保存，避免同一课程的字幕上下跳动。

## 内置样式

工作台内置四种固定基础样式：

- 深蓝底白字：当前课程默认样式，适合大多数浅色页面。
- 白字描边：透明底板、白字和深色描边，画面占用最少。
- 暖白纸片：暖白底、深蓝字和轻阴影，与课程纸张视觉一致。
- 黄色重点：黄色底、深蓝字，用于需要更强提示感的版本。

预设决定字体颜色、底板颜色、圆角、阴影和描边。位置、最大宽度、字号和底板透明度作为全局微调项保留，切换预设时不会重置这些微调值。

## 数据结构

项目根节点增加 `captionStyle`：

```json
{
  "preset": "navy",
  "x": 960,
  "y": 998,
  "maxWidth": 1500,
  "fontSize": 34,
  "backgroundOpacity": 0.9
}
```

旧项目没有该字段时，迁移过程补入默认值；导入、保存、浏览器草稿、撤销、重做和版本快照均保留该字段。项目校验限制位置和尺寸为有限数值，字号与最大宽度大于零，透明度位于 0 到 1，预设必须属于内置列表。

## 渲染与拖动

字幕渲染器只从项目级 `captionStyle` 读取样式。编辑台、独立预览和生成的 HyperFrames 页面复用同一渲染函数。

工作台在当前字幕可见时，根据实际字幕框尺寸绘制字幕选择框。拖动开始时保存完整项目快照；移动过程中实时更新 `captionStyle.x` 和 `captionStyle.y`；松开鼠标形成一次撤销记录；取消拖动则恢复原值。字幕选择框不改变当前字幕文字或时间，也不会选中页面元素。

拖动位置限制在画布范围内，并为字幕框保留最小可见区域。右侧数值输入同样执行范围校验。

## 兼容性与失败处理

旧项目在载入时自动获得当前深蓝底白字样式，不改变已有字幕的视觉结果。无字幕的时间点不显示字幕选择框，用户仍可通过任意字幕时间块进入全局设置。

若输入无效，工作台恢复修改前的数据并显示错误；导出检查阻止未知预设或非法数值进入渲染文件。

## 验证

- 模型测试覆盖默认字段、旧项目迁移、四种预设和非法数值。
- 浏览器测试确认拖动一幕字幕后，切换另一幕仍使用相同位置。
- 浏览器测试确认四种预设即时生效，字幕文字与时间仍可单独编辑。
- 撤销和重做测试确认一次拖动只形成一条记录。
- 独立预览和生成页面分别抽帧，与编辑台的位置和样式比较。
- 八个分镜运行 HyperFrames 检查，确认字幕未超出画布且没有遮挡页脚。
