# 课程视频工作台字幕与动效编辑设计

## 目标

让课程视频工作台在保留现有画面编辑能力的同时，可以直接编辑字幕和基础动效时间，并让导出的预览视频默认显示字幕。第二课打开时自动载入当前同步项目，用户不需要再次手动导入 JSON。

## 使用流程

打开第二课工作台后，系统载入 `video/money-market-lesson-02/workbench-project.json`。用户可以在“画面编辑”和“动效编排”之间切换：

- 画面编辑继续负责元素选择、移动、缩放、旋转、图层、文字内容和文本框换行。
- 动效编排显示动画、字幕、旁白关键词和音效时间块。
- 点击时间块会选中对应对象并显示可输入的时间属性。
- 拖动时间块改变开始时间；拖动右缘改变持续时间；输入数值用于精确调整。
- 字幕文字可在右侧直接修改。字幕时间不得超出当前分镜，也不得出现结束早于开始的情况。
- 预览时在画面底部显示当前字幕。字幕采用两行以内的高对比样式，不遮挡页脚和主要教学内容。

## 时间轴结构

时间轴分为三类可编辑轨道：

1. 字幕轨：显示每条字幕文字、开始时间和结束时间。
2. 动画轨：沿用每个元素一个时间块的结构，并补充开始时间、持续时间和旁白锚点输入。
3. 音效轨：显示知识点出现音和翻页过渡音；本次只开放开始时间和音量，不增加复杂音频剪辑功能。

旁白音频保持时间基准，不允许在工作台内拉伸。修改分镜时长时，字幕和音效可以生成待复核的比例调整，音频本身不变。

## 字幕渲染与导出

编辑台预览和独立预览共用同一字幕渲染函数。当前时间落在字幕的开始与结束区间时，字幕显示在安全区内；没有字幕时隐藏字幕容器。

HyperFrames 生成项目时加入相同的字幕层，因此 MP4 默认可见字幕。交付包仍保留独立 SRT 和 MP4 可选字幕轨，方便在剪映中替换样式或重新编辑。导出的 JSON 保存字幕文字、时间和稳定 ID。

## 默认项目载入

课程适配器可以声明一个只读的默认项目 JSON 地址。第二课声明 `workbench-project.json` 后：

- 首次打开时载入该项目。
- 浏览器中同一修订号的更新草稿仍可恢复。
- URL 增加 `fresh=1` 时忽略浏览器草稿并重新载入默认项目。
- 默认项目失效时回退到课程模板，并在状态栏说明原因。

该机制只读取本地文件，不增加服务器写入或发布能力。

## 数据和兼容性

继续使用现有 version 2 项目结构。字幕沿用 `scene.voice.sentences`，动画沿用 `scene.animations`，音效沿用 `scene.soundEffects`。新增界面状态不写入项目文件。未知扩展字段继续往返保留。

旧项目没有字幕或音效时仍可打开，对应轨道显示空状态。导入失败时不部分覆盖当前项目。

## 验收标准

- 第二课打开后可以看到当前同步布局、83 条字幕、147 个动画和19个音效提示。
- 在画面编辑中仍可移动和缩放已拆分的图形与文字。
- 在动效编排中可以拖动动画和字幕块，并用数值精确修改时间。
- 修改字幕文字后，画布预览、保存 JSON、独立预览和重新导入结果一致。
- 播放或拖动时间游标时，画面显示当前字幕。
- 生成的 MP4 默认可见字幕，同时保留独立 SRT 和可选字幕轨。
- 原有模型测试、浏览器交互检查和八分镜 HyperFrames 检查通过。
