# 小啾老师脸部校准与手动调节设计

## 目标

以用户提供的图一为比例基准，修正当前骨骼版小啾老师眼距过窄、眼镜偏小、嘴部偏低的问题，并提供一个不进入课程成片的可视化校准页面，方便后续自行微调脸部结构。

本次只调整脸部和领带锚点，不改变身体、尾巴、翅膀、脚、动作节奏、课程画面或第一课内容。

## 默认结构校准

默认预设需要满足以下视觉约束：

- 左右眼独立定位，眼睛中心间距比当前版本增加约 25% 至 35%。
- 眼镜整体宽度增加，使眼镜约占身体可见宽度的 52% 至 56%。
- 嘴部整体向上移动约 35 至 45 像素，位于两眼中线下方但不紧贴领带。
- 领带保持现有大小，允许单独上下调整，以留出自然的脸部和衣领空间。
- 三套眼睛状态（睁眼、半闭、闭眼）必须共用相同左右锚点，切换时不能横跳。
- 三套嘴型（闭合、半开、张开）必须共用相同中心锚点，讲话时不能上下跳动。

## 资产结构

现有成对眼睛图片拆成左右独立透明 PNG：

- `eyes-open-left.png`、`eyes-open-right.png`
- `eyes-half-left.png`、`eyes-half-right.png`
- `eyes-closed-left.png`、`eyes-closed-right.png`

骨骼 DOM 增加左右眼槽位，但继续保留统一的 `face` 骨骼。眨眼只切换左右眼状态；点头、思考等动作仍移动整个 `face` 骨骼，避免动作与校准参数争夺同一变换属性。

## 可调参数

在角色根节点上暴露四个稳定参数：

| 参数 | 作用 | 建议安全范围 |
| --- | --- | --- |
| `eyeGap` | 两只眼睛中心之间的距离 | 72–120 px |
| `glassesScale` | 眼镜相对默认大小 | 0.9–1.25 |
| `mouthY` | 嘴部垂直位置 | 168–218 px |
| `tieY` | 领带垂直位置 | 232–280 px |

参数通过 `XiaojiuRig.applyFacePreset(rig, preset)` 统一应用。动作 API 不直接写入这些布局值。

## 手动校准页面

新增独立页面 `tune.html`，与 32 秒动作演示分离：

- 左侧显示高对比中性背景上的小啾老师。
- 右侧提供眼距、眼镜大小、嘴部高度和领带高度四个滑块。
- 提供“参考预设”“重置”“导入 JSON”“导出 JSON”功能。
- 页面同时提供睁眼、眨眼、说话、点头四种快速测试，检查布局在动作中是否稳定。
- 草稿保存在浏览器本地，仅在校准页面恢复；正常预览、课程视频和渲染不得读取浏览器草稿。
- 导出的 JSON 包含模式版本、资产版本和四个数值。无效或超范围 JSON 必须整体拒绝，不能部分覆盖。

校准页不提供任意拖拽、旋转、删除或修改动画时间线，避免误伤骨骼结构。

## 预设与数据流

项目默认值保存在 `assets/xiaojiu-face-preset.json`：

1. `XiaojiuRig.mount()` 创建角色。
2. 角色读取项目默认预设，或接受调用方显式传入的 `facePreset`。
3. `applyFacePreset()` 校验并写入 CSS 自定义属性。
4. 校准页滑块只更新当前预览实例，并按需导出 JSON。
5. 正常课程使用项目文件中的已确认预设，不读取校准页本地草稿。

## 验收标准

- 默认静态结构与图一的相对比例接近，眼距不再拥挤，嘴部不再贴近领带。
- 四个滑块调整时实时生效，眼睛不会被拉伸，眼镜、嘴和领带不越出身体。
- 睁眼、半闭、闭眼三个状态切换时左右位置一致。
- 闭嘴、半开、张嘴三个状态切换时中心位置一致。
- 眨眼、说话、点头、思考和挥手动作仍可定位播放。
- 32 秒动作演示和校准页均无运行时错误。
- HyperFrames 检查通过；关键帧人工检查无重叠、背景方块或部件跳位。

## 不在本次范围

- 不制作完整通用拖拽布局编辑器。
- 不修改身体轮廓或重新生成角色形象。
- 不接入第一课视频；待用户确认新版结构后再单独替换。
- 不导出正式课程 MP4。
