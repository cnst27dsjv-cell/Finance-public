# L1-1-1《什么是储蓄》动画设计

## 目标与范围

将学习中心中 L1-1-1 的动画占位内容替换为可交互的网页动画。首集不使用任何角色素材，但预留讲解者位置，以便后续接入“小啾老师”。本次不制作视频导出、不添加配音、不改动其他课程。

## 教学目标

学习者完成本集后，应理解：储蓄是将暂时不用的钱留给未来；储蓄能够帮助安排消费、保障资金安全，并获得利息。

## 视觉与交互方案

采用响应式 SVG 图解动画，使用项目现有浅色蓝灰配色。动画由可控时间线驱动，提供播放、暂停和重播；用户偏好减少动画时，直接展示场景终态并保留文字信息。

动画区域包含一个空的讲解者图层，首集不渲染角色。未来接入小啾老师时，只新增角色组件和动作，不改变知识场景、时间线或播放控制。

## 分镜

| 场景 | 内容 | 关键画面 |
| --- | --- | --- |
| 标题 | “什么是储蓄” | 标题和副标题淡入 |
| 对比 | 今天花掉 / 存起来 | 钱包、消费物品与存钱罐的左右对照 |
| 累积 | 钱留给未来 | 金币依次进入存钱罐并形成余额 |
| 资金流 | 为什么会有利息 | 储户 → 银行 → 企业 → 利息回到储户 |
| 要点 | 三个好处 | 延迟消费、资金安全、获得利息三张知识卡 |
| 总结 | 一句话记忆 | “储蓄 = 今天的安排 → 明天的选择” |

## 组件边界

- `SavingsAnimation`：SVG 场景、时间线与播放状态。
- `Learning`：仅负责在 L1-1-1 中渲染动画并使用现有的“完成学习”流程。
- 动画数据：场景顺序、字幕和总时长放在组件内的常量，后续多课程时再抽离，不提前建立通用动画引擎。

## 行为与无障碍

- 初次进入自动播放；播放结束后停在总结场景。
- 播放、暂停、重播按钮具有明确文字标签。
- 用字幕和图标表达全部知识点，不能只靠运动传达信息。
- 检测 `prefers-reduced-motion`：不播放连续动画，直接显示完整图解。
- 小屏幕保持 16:9 画面比例，文字不截断。

## 验收标准

- 仅 L1-1-1 不再显示“动画讲解正在加载中”的占位内容。
- 可以播放、暂停、重播，且重复播放不会残留错误状态。
- 桌面与移动宽度下内容可读。
- 减少动画偏好下仍可完整学习。
- 后续可在讲解者图层加入小啾老师，而无需重写场景。

## 非目标

- 不使用或裁切当前角色设定图。
- 不制作 MP4、TTS、背景音乐或完整视频流水线。
- 不改动课程解锁、测验或用户进度逻辑。
