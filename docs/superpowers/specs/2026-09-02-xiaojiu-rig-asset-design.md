# 小啾老师 2D 分层骨骼资产设计

## 目标

把现有小啾老师水彩角色整理成一套可复用的 2D 分层骨骼资产。它既能在 HyperFrames 课程视频中精确拖动时间轴和渲染，也能在后续网页课程中直接复用。第一阶段只制作角色动作资产和独立演示，不立即重做 L1-1 四分钟视频。

## 方案比较

1. **整张表情贴图切换**：制作最快，但身体各部位仍一起移动，无法解决僵硬感。
2. **分层骨骼切片 + GSAP（采用）**：保留水彩 PNG，按父子节点控制身体、翅膀、眼睛、嘴、眼镜和领带；制作量适中，最适合当前代码视频工作流。
3. **Live2D / Spine**：可做网格变形和更精细的转面，但需要专用编辑器、模型工程和额外运行时，现阶段成本过高。

## 资产结构

资产包保存到 `video/shared/xiaojiu-rig/`：

- `assets/source/`：原始部件图和不可变源文件。
- `assets/parts/`：透明的身体、眼睛、闭眼线、眼镜、三档嘴型、领带、左右脚和翅膀姿势。
- `xiaojiu-rig.css`：部件尺寸、层级、肩部和面部旋转中心。
- `xiaojiu-rig.js`：角色 DOM 模板、挂载接口和动作函数。
- `README.md`：在其他课程中接入角色的方法、动作参数和限制。
- `demo/`：独立 HyperFrames 动作展示工程，不与第一课耦合。

## 骨骼与层级

- `rig-root`：角色在场景中的位置、整体缩放和进退场。
- `body-bone`：呼吸、下蹲、弹起、点头时的主体节点。
- `face-bone`：眼睛、闭眼线、眼镜和嘴；跟随身体并允许轻微视线偏移。
- `wing-left-bone` / `wing-right-bone`：以肩部为旋转中心，切换折叠、抬起和展开翅膀。
- `tie-bone`：以领口为旋转中心，动作结束后产生短暂滞后摆动。
- `feet-bone`：落地和弹起时做轻微压缩，不单独行走。
- `pointer-bone`：代码绘制的教鞭，挂在讲解侧翅膀上，仅在讲解动作中显示。

主身体源图包含固定翅膀，因此需先制作一张补齐肩部和身体轮廓的 `body-clean.png`。所有最终部件必须是真实 Alpha PNG，不能使用棋盘格像素、白色矩形或 CSS 混合模式冒充透明。

## 动作资产

第一版包含八个可组合动作：

1. `idle`：呼吸、轻微重心变化和领带延迟。
2. `blink`：自然双眼眨动，可叠加在其他动作上。
3. `talk`：闭合、半开、张开三档嘴型，支持指定时长。
4. `teach`：抬翅、握教鞭、指向画面并回收。
5. `think`：身体侧倾、视线偏移、翅膀靠近脸部。
6. `surprise`：身体压缩后弹起、双翅张开、嘴型张大。
7. `nod`：两次短促点头和眼镜轻微滞后。
8. `wave`：一侧翅膀抬起并往返挥动三次。

动作通过 `XiaojiuRig.addAction(timeline, rig, name, options)` 加入外部 GSAP 时间轴。每个动作都是有限次数、可 seek、无随机数、无定时器，不创建自己的无限循环。

## 演示与验收

独立演示为 1920×1080、约 24–30 秒，依次展示八个动作和动作名称。验收标准：

- 在深色、彩色和课程纸张三种背景上都没有白底或棋盘格残留。
- 翅膀旋转中心位于肩部，不漂浮、不穿过身体。
- 眼镜、领带存在合理的次级跟随，嘴型切换不露出重复嘴。
- 每个动作可以单独调用，也可以与 `blink`、`talk` 叠加。
- HyperFrames `check` 的运行、布局、动作和对比度检查通过。
- 先交付预览，不在用户确认前渲染最终视频，也不替换第一课角色。

## 非目标

- 不制作 360° 转面、走路循环、口型音素识别或 Live2D 网格变形。
- 不修改课程脚本、题目、旁白和第一课时间结构。
- 不把动作代码绑定到某一节课程的具体画面坐标。
