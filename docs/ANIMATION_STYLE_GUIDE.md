## InvestQuest 教学动画 — 风格指南 & IP 规范

版本：v1.0
适用范围：所有 L1-L5 课程教学动画

---

### 一、IP 形象 —「金币小精灵 · 元宝」

**名称：** 元宝（Yuanbao）

**外形描述：**

元宝是一枚拟人化的金色硬币精灵。身体是圆润的金色圆盘，正面刻有「¥」符号（像素风格描边），背面隐约可见花纹。面部占身体约 1/3 面积，有一双大而圆的像素化眼睛（2×2 像素高光点），弯弯的微笑嘴巴用简单线条表达。头顶有一小簇像素火焰状的光芒，随情绪变化颜色（讲解时暖黄色、强调时亮白色、警告时橙红色）。两侧伸出小小的像素手臂和腿，手脚都是简化的圆点。

**性格特征：**

热情、耐心、有点俏皮。像一个懂投资的好朋友，用轻松的语气讲道理，偶尔用夸张的动作比划数字。讲解重点时会竖起一根手指，说到复利增长时会兴奋地跳起来。

**表情库（动画常用）：**

- 微笑讲解（默认态）：弯弯眼、上扬嘴角
- 兴奋发现：放大眼睛、头顶光芒变亮、双手举高
- 认真强调：半闭一只眼、伸出一根手指
- 担忧警告：微微皱眉、头顶光芒变橙
- 庆祝成就：跳跃、撒花、头顶出现星星

### 二、视觉风格 — 像素/手绘混搭

**画面构成原则：**

- 背景层：像素风格，8-bit 质感色块，几何化的场景元素（如城市天际线、银行建筑、图表网格）
- 角色层：手绘质感线条，元宝和辅助角色用手绘风格，保持有机温度
- 数据层：像素化图表和数据可视化，数字用像素字体呈现，增强「游戏感」

**配色方案：**

| 用途 | 色值 | 说明 |
|------|------|------|
| 主金色 | #F5C542 | 元宝身体主色 |
| 深金描边 | #C49B2A | 像素描边和阴影 |
| 背景深蓝 | #1A2744 | 与产品 Oxford Blue 一致 |
| 背景暖白 | #F8F6F2 | 亮色场景背景 |
| 强调红 | #E74C3C | 上涨、正收益 |
| 强调绿 | #27AE60 | 下跌、负收益 |
| 辅助蓝 | #495B7D | 文字、图表辅助色 |
| 高光白 | #FFFFFF | 光芒、高亮 |

**字体规范：**

- 旁白字幕：中文无衬线体（如思源黑体），16-20px
- 数据数字：像素字体（如 Press Start 2P），增强游戏感
- 标题/重点词：手写体风格，突出手绘质感

**动画节奏：**

- 每个课时动画时长：60-90 秒
- 场景切换：像素化转场（如百叶窗、溶解、像素方块扩散）
- 角色动作：12fps 手绘动画感（逐帧跳切，不用平滑过渡）
- 数据动画：数字滚动、柱状图逐格生长、折线图逐点绘制

### 四、音效规范

- 背景音乐：轻快的 chiptune/8-bit 风格电子音乐，节奏适中
- 音效：像素风提示音（叮咚、金币声、翻页声）
- 旁白：中文男声/女声，语速适中，亲切自然，类似科普博主风格

### 五、通用片头片尾

**片头（5 秒）：**

像素化的 InvestQuest Logo 从方块拼合出现 → 元宝从画面底部弹跳入场 → 挥手打招呼 → 标题文字手写体浮现（如「储蓄基础」）

**片尾（5 秒）：**

元宝竖大拇指 → 关键知识点像素卡片快速闪过回顾 → 「完成学习！」像素文字 → 金币散落特效
