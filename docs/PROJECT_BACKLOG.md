# InvestQuest 项目完善项存档

更新时间：2026-09-01

## 项目判断

InvestQuest 当前是一个面向投资新手的中文游戏化学习平台原型。主流程为：课程学习 → 投资模拟 → 量化实验。现有页面和主要交互已经成形，但量化部分仍以教学展示和随机模拟为主。

## P0：必须先处理

- 修复 `npm run build`：`Home.tsx` 和 `QuantLab.tsx` 中存在未使用的 `hasCompletedCourse`，导致 TypeScript 构建失败。
- 恢复量化实验室的真实解锁条件，移除本地调试用的强制解锁逻辑。
- 统一首页、模拟器、个人中心的资产估值口径，特别是期权/期货的合约乘数和保证金计算。
- 增加核心逻辑测试：课程解锁、测验判定、买卖资金、手续费、止损、定投、资产总值。

## P1：核心产品能力

- 实现可执行的中文伪代码子集，至少支持均线交叉和 RSI 两个策略模板。
- 将回测从随机曲线改为基于可复现历史/模拟行情的数据执行。
- 让回测结果真正受策略代码、手续费、滑点和初始资金影响。
- 让参数优化真正遍历参数组合并调用回测引擎。
- 将激活策略接入模拟交易，按行情生成信号并记录交易。
- 将技术指标计算结果接入策略信号和回测引擎。

## P2：交易系统完善

- 完善限价单委托、成交、撤单和历史委托记录。
- 增加期权到期、行权/作废和期货到期、保证金风险、强平规则。
- 明确涨跌停时的成交限制和提示。
- 处理定投资金不足、持仓数量变化、止损数量同步等边界情况。
- 增加市场模拟的随机种子或回放机制，方便复现问题和教学演示。

## P2：课程与教学内容

## 动画制作方向存档

首选路线：在现有 React/Vite 项目中使用 SVG + Framer Motion/GSAP 制作可交互课程动画，并保留动画场景数据化能力。需要导出视频时，再考虑 Remotion；如果制作公式推导或复杂数学可视化，可单独评估 Manim。

GitHub 调研得到的候选参考：

- `sdras/svg-workshop`：SVG、React、GSAP 动画教学资料，适合学习基础和交互式 SVG。
- `znyupup/knowledge-explainer-skill`：Markdown 到 Remotion 教育讲解视频的思路，适合后续批量生成视频。
- `vorojar/svg-draw-motion`：SVG 手绘、时间线、字幕、音频和 MP4 导出工具，适合研究科普动画制作流程。
- `3b1b/manim`：解释型数学动画引擎，适合公式和数学概念，不适合作为当前 Web 课程动画的唯一技术栈。
- `metaforismo/mote-studio`：可编辑 SVG 角色和动画时间线工具，适合参考角色资产管理和导出方式。

## 第一部课程动画建议

建议先制作 L1-1《什么是储蓄》或 L1-1-2《单利与复利》，控制为 60-90 秒、4-6 个场景：问题引入 → 金宝角色解释 → 钱的积累可视化 → 单利/复利对比 → 一句话总结 → 小测验入口。

验收标准：可在学习页面播放；支持暂停/重播；移动端不溢出；尊重 `prefers-reduced-motion`；字幕与动画同步；不依赖外部视频服务；动画资源可复用和替换。
