# 第一课画面布局编辑器

打开编辑器：<http://127.0.0.1:3010/layout.html>

## 调整画面

1. 在左上角选择 S01–S08 分镜。
2. 直接点击画面元素，或从左侧图层列表中选择元素。
3. 普通元素可以拖动位置，并用边框控制点调整大小和旋转。
4. 文字元素选中后会出现蓝色左右手柄。拖动它们只改变文字框宽度，不改变字号；拉宽后可以把换行文字排回同一行。
5. 线条可以拖动整条线；选中后还可以调整端点和弯曲控制点。
6. 圆形可以移动并调整半径，SVG 文字可以直接移动。
7. 顶部提供撤销、重做、重置本页和预览模式。

编辑内容会自动保存在当前浏览器中，刷新页面不会丢失。

## 调整完成后

直接点击“下载 JSON”，把下载的文件发给我即可。无需先点“应用 JSON”。

“导入 JSON”用于以后继续修改之前下载过的配置。编辑器里的草稿不会直接改变正式视频或 MP4；我收到最终 JSON 后，会把它写入正式视频配置，并保留现有动效。
